# Accessibility Audit Report

## Website Audited
My collection of Dummy sites – Practical testing for beginners

## Website Purpose
This website is a Ministry of Testing community discussion that provides a collection of dummy websites for beginners to practice software testing.

## Testing Method
- Google Lighthouse accessibility audit
- Keyboard-only navigation using Tab and Shift + Tab

## Accessibility Findings

### 1. Insufficient Color Contrast
Lighthouse identified a color contrast issue between foreground and background content.

**Priority:** Medium

### 2. Links Without Discernible Names
Lighthouse identified links that do not have sufficiently clear accessible names.

**Priority:** High

### 3. Touch Targets Are Too Small
Lighthouse reported that some touch targets do not have sufficient size or spacing.

**Priority:** Medium

## Manual Testing
The page was also checked using keyboard-only navigation to identify navigation and focus-related usability issues.

## Recommendations
- Improve foreground/background color contrast.
- Give links clear and descriptive accessible names.
- Increase the size and spacing of touch targets.
- Ensure all interactive elements can be reached and understood using keyboard navigation.

## Conclusion
The website provides useful software-testing resources for beginners, but several accessibility improvements can make the page easier to use for people with different accessibility needs.
