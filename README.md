# Accessibility & Repository Architecture Audit

## Project Overview
This project audits a public-facing website for accessibility
and documents the findings.

## Website Audited
India.gov.in

## Accessibility Testing
- Google Lighthouse
- Keyboard-only navigation

## Findings
Five accessibility or architecture issues were documented
with evidence and remediation priority.

## Project Structure
- client – frontend files
- server – backend files
- docs – audit documentation
- tests – testing files

## Local Setup
Clone the repository and open the project locally.

## First Feature
The first feature slice focuses on improving accessible
navigation and user interaction.
